# case1111 建筑与结构交互模型

10 / 12 Heather Green 的官方本地网页包，用于 GitHub Pages 预览。

- [10 号](https://xian-xwz.github.io/case1111-interactive/lot10/)
- [12 号](https://xian-xwz.github.io/case1111-interactive/lot12/)

现有 w3-staging/lot10/ 与 w3-staging/lot12/ 链接同步更新。默认显示完成地形，支持现状切换和地形半透明。选择“楼面与桩基础”或“搁栅布置平面”查看本轮结构更新；点击构件查看 Detail、来源、条件计算和适用的连接节点图。

搁栅按原图 BY OTHERS 设计布置；孔底采用工程师指定的 CGL 以下 1.0 m，木桩与混凝土分开。计算展示为条件复算，部分连接安装、现场基准与完整工程复核仍待确认。完成地形包含明确标识的示意整地。

本仓库只发布交互模型及获准展示的连接图，不含项目图纸、会议原件或计算原文件。用户视觉确认与工程确认尚待完成。
